Si vuole simulare un sito web che conta le visite in tempo reale. Due visitatori, Anna e Bruno, accedono contemporaneamente al sito e ognuno effettua 5 visite. Il contatore delle visite è condiviso tra i due visitatori.

Scrivere un programma Java che:

Definisce una classe ContatoreVisite
Definisce una classe Utente che estende Thread
Definisce una classe SitoWeb con il main

Nel main bisogna anche stampare il valore del contatore finale.
